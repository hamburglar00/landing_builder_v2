# Animación del chat a 520 ms — 23/10/2026

La apertura y el cierre pasan de 280 a 520 ms para apreciar el movimiento desde
y hacia el botón. Se conserva la curva de expansión y la posición de origen.
El desvanecimiento del panel dura 440 ms, el del botón 300 ms y el fondo 520 ms.
El temporizador de respaldo termina a los 560 ms y los avisos aplazados esperan
600 ms, después de la contracción. Movimiento reducido sigue siendo inmediato.

La implementación canónica de Rey se comparte mediante
`scripts/sync-gateway-chat-motion.mjs`. Los cuatro gateways usan la versión
`chat-motion-520-1` para invalidar la caché del JS y el CSS.

Validación con `scripts/check-gateway-entry-ux.mjs`: Chromium y WebKit, cuatro
gateways, escritorio y móvil, inversión rápida de apertura/cierre, reutilización
del iframe, toques en el casino durante el cierre y movimiento reducido.
No modifica Atrio, API2, Panel3 ni la base de datos.
